# StationOS

StationOS is a web-based telemetry and automation platform for Stationeers.

Using the game's HTTP API, IC scripts can export live station data to an Express backend where it is visualized through a set of operational dashboards. The system also supports sending commands and automation decisions back into the game, enabling two-way communication between Stationeers and external services.

Current features include:

* Power monitoring and generation control
* Battery status and automation
* Weather monitoring and storm tracking
* Room atmosphere monitoring
* Lighting and occupancy reporting
* Real-time event and alert system
* External automation through HTTP endpoints

The goal of the project is to provide a station-wide operations console similar to a SCADA system, allowing players to monitor and manage complex bases from a single interface.
